# Contributing to Local AI Hub

Thanks for helping improve Local AI Hub.

## Issues and requests

Use the repository's [issue chooser](https://github.com/Local-AI-Hub/LocalAIHub/issues/new/choose):

- File a bug report for reproducible incorrect behavior.
- Request troubleshooting help when you are blocked.
- File a feature request for a proposed improvement.

Before submitting, read the [troubleshooting guide](docs/troubleshooting.md), include exact reproduction steps, and say whether an affected tool is managed by Local AI Hub or installed externally.

## Safe diagnostics

In Local AI Hub, open **Settings -> Support and Diagnostics**. Use **Copy system info** for a short summary or **Create diagnostics bundle** for a reviewable ZIP. Nothing is uploaded automatically.

Review every file before sharing. Do not post API/provider keys, PATs, tokens, passwords, private prompts, private media, model files, generated outputs, or other sensitive data. Prefer sanitized error text over screenshots when text is enough.

## Development changes

Keep changes focused and describe how they were validated. The basic local setup and build commands are documented in the [README](README.md#development). Do not run live provider-backed validation unless the change specifically requires it and you understand the quota and privacy impact.
