# Lower Third Caption

This managed HyperFrames project lives under Local AI Hub managed storage in projects/hyperframes after it is created. The template files are copied into each new project, so editing one project does not change other projects or the packaged template.

Remote assets are blocked for this first integration. Keep scripts, styles, images, audio, and video local to this project folder, preferably under assets.

HyperFrames projects can execute HTML, CSS, and JavaScript when rendered. Open and render only projects you trust.
