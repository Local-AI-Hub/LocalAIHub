# Local AI Hub Landing Page

This directory contains the static Local AI Hub landing page published through GitHub Pages. It has no build step, backend, analytics, cookies, forms, or external JavaScript dependencies.

## Preview Locally

Open `index.html` directly in a browser:

```powershell
Start-Process .\docs\index.html
```

No package installation or build command is required.

The page references screenshots in `screenshots/`. Keep that relative directory structure intact when previewing or publishing the `docs/` folder.

GitHub Pages is configured to publish from the `main` branch and `/docs` folder.
