# Local AI Hub v0.48.0

Local AI Hub 0.48.0 improves Pipeline Wizard structured-output reliability, diagnostics, and media-composition intent handling.

## Highlights

- Improved Pipeline Wizard structured-output reliability.
- Fixed valid Wizard Intent IR responses being mislabeled as recovered or malformed when optional `recipeId` was omitted or null.
- Added more accurate classification for provider failures, empty replies, malformed or wrapped JSON, schema mismatches, unsupported enums, missing required fields, lowering failures, graph repair, and truncated output.
- Preserved useful Gemini structured-output diagnostics, including finish reasons, truncation, usage, prompt feedback, and safety details.
- Improved the Groq structured-output path where supported.
- Added an opt-in live wizard validation script for drafting-only provider checks. It does not execute pipelines or generate media.
- Added wizard awareness of Media Composition modes: Image slideshow, Video sequence, and Single video mix.
- Reduced wizard over-configuration so drafts focus on topology, structural modes, and output types instead of detailed node settings.
- Kept deterministic recovered-draft fallback available as a safety net.
- Clarified user-facing wizard messages so successful structured drafts report intent graph creation instead of recovered or malformed output.

## Validation

Release validation includes the full offline build and verifier set documented for 0.48.0. Provider-backed Pipeline Wizard validation and live Groq planner testing are intentionally excluded because they are manual, quota-consuming checks.

## Known Limitations

- Live wizard validation is opt-in and is not part of normal release checks.
- Provider quota and rate limits can affect live wizard validation.
- Wizard detection remains partly phrase and intent based.
- Deterministic fallback remains active for unsupported or malformed model output.
- The landing page and demo video have not been updated yet.
- The existing Vite large-chunk warning may still appear.

## Download

1. Open the Assets section below.
2. Download `LocalAIHub-Setup-0.48.0.exe`.
3. Run the installer and follow the Windows instructions.

The `.exe` is the installer. The `.blockmap` and `latest.yml` files support the application's release and update flow.

## Windows SmartScreen and Unsigned Installer

Local AI Hub is currently distributed as an unsigned Windows app. Windows SmartScreen, browsers, or antivirus software may warn before the installer runs.

Download the installer only from the official Local AI Hub GitHub release. If SmartScreen appears, choose `More info`, verify that the file is the release asset you intended to download, and select `Run anyway` only if you trust the source and want to continue.
