# Local AI Hub 0.59.0

- Agents can search Model Manager catalogs, inspect target compatibility and available disk space, select model variants, install or remove models, and track progress through MCP.
- Model Manager improves partial-name and filename searches, Ollama tag lookup, Hugging Face fallback queries, and artifact selection. Compatible results rank ahead of blocked repositories. Generic upstream filenames use source identity to distinguish downloads.
- Image searches recognize generic Diffusers weights that cannot be identified as standalone checkpoints. Hugging Face detail requests run in smaller batches and report rate limits.
- Pipeline agents can discover node configuration and inference parameters. RVC voice conversion exposes pitch shift, pitch extraction method, retrieval mix, RMS mix, and consonant protection in pipeline configuration.
- Includes fixes across the Library, Store, Recorder, Settings, Statistics, and Pipelines views, including deferred loading of pipeline outputs.
