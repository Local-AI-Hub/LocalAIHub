# Local AI Hub v0.39.0

Local AI Hub 0.39.0 focuses on multi-interface launch behavior, official desktop companion support, and clearer repair, uninstall, Store, and Library states.

## Highlights

- Added multi-interface launch modes so supported tools can expose web, managed local, official desktop, and launcher-based entry points more clearly.
- Updated launch, repair, and uninstall wording to use capability-specific labels instead of generic actions where the tool supports multiple interfaces.
- Added ComfyUI Desktop official companion integration and related detection/launch fixes while preserving the existing WebUI behavior.
- Added InvokeAI Desktop Launcher integration and related detection/launch fixes alongside the managed InvokeAI install flow.
- Added OpenCode Store and Library integration for desktop usage.
- Fixed OpenCode desktop detection for `%LOCALAPPDATA%\Programs\@opencode-aidesktop\OpenCode.exe`.
- Fixed Ollama Store duplication and launch/store state handling so installed desktop and managed states stay clearer.
- Retested WebUI/Desktop launch behavior across the updated launch-mode architecture.
