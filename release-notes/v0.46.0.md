# Local AI Hub v0.46.0

Local AI Hub 0.46.0 adds interactive pipeline recording and makes background loading safer when leaving Model Manager or Statistics.

## Highlights

- Added a Pipeline Builder Record Input node that pauses a run for interactive audio or video capture.
- Added mode-aware artifact typing, wiring protection, validation retry, and safe rerecording controls.
- Model Manager and Statistics now cancel or discard tab-owned background loads when the user leaves those tabs; Pipelines and active runs are intentionally unaffected.

## New Features

- Record Input supports microphone, screen or region, screen plus microphone, webcam, webcam plus microphone, system audio, and screen or region plus system audio where the Recorder backend supports them.
- Record Input emits the correct audio or video artifact type and prevents invalid wiring.
- Captures are stored as same-run generated pipeline artifacts.
- Validation retry can request a fresh recording and safely adjust same-mode settings including FPS, region, display, microphone, webcam, and capture target.
- Changing capture mode removes incompatible outgoing edges or blocks the change when the output type would invalidate the graph.
- The pipeline wizard understands Record Input at a minimal, mode and output-type-aware level.

## Fixes

- Model Manager catalog and local inventory loads cancel or become stale when leaving the tab.
- Statistics background loading cancels or becomes stale when leaving the tab.
- Existing Recorder and Pipelines behavior is preserved, including active pipeline runs.

## Known Limitations

- The Record Input wizard provides minimal mode selection, without advanced device or region configuration.
- Window capture is not supported.
- Screen plus webcam is not supported.
- System audio plus microphone and webcam plus system audio are not supported.
- Hardware encoder selection is not supported.
- This release does not add broad Pipelines tab background cancellation.
- Other hardware and provider-dependent areas remain listed in the [README untested-features section](../README.md#untested-features-as-of-v0460).

## Download

1. Open the Assets section below.
2. Download `LocalAIHub-Setup-0.46.0.exe`.
3. Run the installer and follow the Windows instructions.

The `.exe` is the installer. The `.blockmap` and `latest.yml` files support the application's release/update flow and normally should not be downloaded or opened manually.

## Windows SmartScreen and Unsigned Installer

Local AI Hub is currently distributed as an unsigned Windows app. Windows SmartScreen, browsers, or antivirus software may warn before the installer runs.

Download the installer only from the official Local AI Hub GitHub release. If SmartScreen appears, choose `More info`, verify that the file is the release asset you intended to download, and select `Run anyway` only if you trust the source and want to continue.
