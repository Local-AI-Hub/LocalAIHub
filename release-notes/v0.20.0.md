## Local AI Hub v0.20.0

- Bounded pipeline UX and collection-validation release on top of the existing app and pipeline builder.
- Improves pipeline builder usability with collapsible sections, saved pipeline name/description editing, drag-to-pan, wheel zoom on canvas hover, and more room for larger graphs.
- Makes the left sidebar feel steadier across pages with sticky menu behavior, a sticky hardware panel, and follow-up sidebar cleanup.
- Validation now accepts a Collection as a whole-collection input instead of requiring a per-item flow for this step.
- Collection -> validation -> retry-loop workflows now run correctly with whole-collection validation.

Known bounds:
- This is not a broad redesign of the full app.
- Collection validation in this release is whole-collection validation, not per-item fanout or mapping.
- Machine-specific Automatic1111 or Fooocus runtime issues were not part of this release.
