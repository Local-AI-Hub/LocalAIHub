# v0.25.0 - Progressive Statistics loading and dashboard responsiveness

## Highlights

- Makes the Statistics page feel responsive immediately instead of waiting for slower recursive storage and model scans.
- Adds clear loading, long-load, empty, error, retry, and refresh states so the page no longer shows fake zeroed statistics while real data is still loading.
- Splits Statistics loading into fast core statistics and slower storage/model sections with independent failure handling.
- Adds timing and cache diagnostics for Statistics loading without logging secrets or large payloads.

## Statistics loading UX

- Shows skeleton/loading UI as soon as Statistics opens.
- Removes misleading empty or zero statistics while data is still loading.
- Adds plain-English long-load messaging when local file scans take longer than expected.
- Adds a retryable error state for failed Statistics loads.
- Adds an empty state when no meaningful launch, storage, or VRAM statistics exist yet.
- Keeps existing data visible with an updating banner during manual refresh.

## Progressive statistics sections and caching

- Loads core launch, drive, and VRAM statistics before slower storage/model sections finish.
- Loads storage and model size sections independently so failures there no longer fail the entire Statistics page.
- Adds section-level 60-second caching for automatic refreshes.
- Keeps manual refresh as an intentional cache bypass.
- Guards duplicate in-flight section loads to avoid stacking redundant scan work.

## Diagnostics and performance visibility

- Adds timing logs for core Statistics loading.
- Adds timing logs for storage and model scan sections.
- Adds cache hit, cache miss, and in-flight reuse diagnostics for section loading.
- Keeps diagnostic payloads limited to timings, counts, section names, and cache state.

## Known limitations

- Recursive storage and model scans can still be slow on large installs, but they no longer block the whole Statistics page.
- Statistics does not yet use a persistent analytics database.
- UI density and no-scroll redesign work is deferred to v0.26.0 or later.
- AudioCraft continuation mode and generation controls remain future work.
- The full Graph Workflow preset registry remains future work.
