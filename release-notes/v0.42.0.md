# Local AI Hub v0.42.0

Local AI Hub 0.42.0 focuses on planner reliability, wizard validation safety, OpenCode update reporting, and stronger Media Composition retry/audio behavior.

## Highlights

- Fixed OpenCode update detection and reporting when official Windows installers do not expose a clear version after update.
- Made provider-backed Pipeline Wizard live validation opt-in/manual only so release and CI-style validation do not consume provider quota.
- Hardened Pipeline Wizard reliability and generalized stress-test coverage.
- Improved longform planner JSON reliability, including provider JSON-mode safeguards and deterministic fallback handling.
- Added longform chunked planning with compact global summary context for larger plans.
- Kept scene `imagePrompt` content cleanly separated from scene metadata and draft fields.
- Repaired longform timing metadata and minimum image-count behavior.
- Clarified Media Composition audio mix volume semantics with source-relative SFX gain handling.
- Added cross-layer SFX guard behavior for overlap prevention.
- Expanded Media Composition retry settings for timing, transitions, SFX guard controls, and per-layer/global volume controls.
- Expanded verifier coverage for longform planner reliability, wizard opt-in behavior, launch modes, planning, and Media Composition regression paths.
- Updated the README untested-features heading for v0.42.0 while preserving the existing untested feature list.
