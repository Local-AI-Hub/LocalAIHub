# v0.31.0 - Subtitle export, caption styling, and media utility polish

## Highlights

- Adds Export Subtitles under Deterministic Media Operations for reusable `.srt` and `.vtt` subtitle artifacts.
- Adds practical Burn Subtitles / Captions styling controls with safe user-facing dropdowns for color, font, and placement choices.
- Adds captioned-video templates for exporting subtitle files or generating burned-caption videos from Whisper transcript output.
- Extends Extract Video Frame with Timestamp mode while preserving First frame and Last frame behavior.
- Polishes Trim Media and subtitle-control labels for clearer media utility workflows.
- Ships with rebuilt `0.31.0` Windows installer artifacts and targeted release verification.

## Export Subtitles

- Adds the Export Subtitles node under Deterministic Media Operations.
- Converts transcript, caption, or manual subtitle text into reusable subtitle file artifacts.
- Supports `.srt` and `.vtt` output.
- Supports auto mode, timed transcript/Whisper segments, and manual text lines with `durationPerCaptionSeconds`.
- Produces normal file artifacts with `.subtitle.json` sidecars.
- Does not require video input and does not burn captions into video.

## Captioned-video templates

- Adds the "Export subtitles from video" template: Video Input -> Extract Audio -> Model Step Whisper transcription -> Export Subtitles -> File Output.
- Adds the "Generate subtitled video from video" template: Video Input -> Extract Audio -> Model Step Whisper transcription -> Burn Subtitles / Captions -> Video Output.
- Both templates instantiate as editable pipelines.
- Both templates use the existing Whisper readiness behavior.

## Burn Subtitles styling

- Adds caption styling controls for font size, outline, shadow, vertical margin, text color, outline color, font preset, bold, italic, position/alignment, background box, and background opacity.
- Uses safe dropdowns for color and position settings instead of exposing raw FFmpeg/ASS syntax.
- Corrects subtitle positioning end-to-end so Bottom, Top, and Center render where labeled.
- Records the full user-facing burned-subtitle style configuration in metadata.
- Renames "Bottom margin" to "Vertical margin" because ASS MarginV applies to both top and bottom positions.

## Extract-frame and Trim Media polish

- Extends Extract Video Frame with Timestamp mode.
- Timestamp mode supports typed decimal seconds.
- Extracted-frame metadata and sidecars record `framePosition` and `timestampSeconds`.
- First frame and Last frame modes remain unchanged.
- Clarifies Trim Media labels: Start seconds is now Start time, End seconds is now End time, and Duration seconds remains Duration seconds.
- Trim Media numeric fields now support direct typed decimal values instead of forcing spinner-arrow input.

## Verification and known limitations

- Targeted release verification covered media utilities, local video pipeline behavior, media composition, Model Step behavior, collectionMap behavior, pipeline templates, audio pipeline behavior, and the UI production build.
- Export Subtitles creates subtitle files; Burn Subtitles / Captions is still the node that renders captions into video.
- Manual text-line subtitle timing is fixed-duration and is not speech-aligned unless the user writes or times lines accordingly.
- Advanced freeform font, color, and ASS styling is intentionally not exposed.
- Split Video Into Clips was intentionally not implemented because Trim Media already covers the practical trimming use case.
- One harmless LF/CRLF warning for `PipelineBuilderPanel.jsx` may remain intentionally deferred.
