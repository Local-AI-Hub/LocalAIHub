# v0.28.0 — Built-in Pipeline Templates and starter workflows

## Highlights

- Adds built-in starter pipeline templates that are available immediately after install.
- Lets templates instantiate normal editable pipelines on the canvas without changing New Pipeline or Pipeline Wizard behavior.
- Labels template readiness honestly as ready, configurable, missing requirements, or unavailable.
- Explains missing tools, providers, models, and presets instead of presenting unavailable workflows as ready.
- Ships with rebuilt `0.28.0` Windows installer artifacts and targeted release verification.

## Pipeline Templates

- Adds starter drafts for text response, image description, simple text to image, prompt collection to image collection, prompt collection with per-item user validation, audio transcription, text to music/audio, AudioCraft continuation, image upscale, image collection upscale, graph workflow from preset, styled prompt collection to image collection, and voiceover to slideshow video.
- Keeps each generated workflow editable after creation.
- Preserves the existing New Pipeline and Pipeline Wizard paths.

## Voiceover to slideshow video template

- Adds an advanced Audio Input -> Whisper transcription -> Planning Packet -> Planner -> Plan Scenes -> collectionMap text-to-image -> Media Composition -> Media Export -> Video Output starter workflow.
- Carries the original voiceover audio into media composition.
- Preserves Whisper timestamp segment metadata into planning packet source artifacts when supported.
- Leaves voiceover file, Whisper config, planner provider/model, image backend/checkpoint/provider, optional Prompt Style, and slideshow timing configurable.

## Template readiness and requirements

- Shows missing Whisper, image runtime, planning provider/model, graph preset, provider, tool, and model requirements in plain language.
- Allows configurable starter drafts to be created even when user choices are still required before running.
- Marks preset-dependent templates unavailable when the required saved preset does not exist yet.

## Build hygiene

- Adds a `.gitattributes` source/binary line-ending policy.
- Splits pipeline templates into a separate Vite chunk to remove the chunk-size warning.
- Reduces the PipelineBuilderPanel lazy chunk size.

## Verification and known limitations

- Verified built-in pipeline templates, media composition, Pipeline Wizard behavior, Model Step behavior, collectionMap behavior, and UI production build for this release.
- Voiceover/slideshow does not yet automatically drive slide durations from transcript segment timings. It preserves timing metadata, but media composition still uses editable `secondsPerItem`.
- Some templates remain configurable or show missing requirements depending on installed tools, connected providers, saved presets, and selected models.
- Pipeline templates are starter drafts, not auto-running workflows.
- One LF-to-CRLF warning may persist for `PipelineBuilderPanel.jsx`; normalizing it would require a large line-ending-only churn pass, so it is harmless and intentionally deferred.
- Full public docs and template walkthroughs can be expanded later if needed.
