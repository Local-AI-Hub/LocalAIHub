# Local AI Hub v0.47.0

Local AI Hub 0.47.0 expands Media Composition from image slideshows into a three-mode video composition workflow while preserving existing slideshow behavior.

## Highlights

- Expanded Media Composition with Image slideshow, Video sequence, and Single video mix modes.
- Video sequence mode composes an ordered collection of video clips, including clips with audio, silent clips, narration, music, and transitions.
- Single video mix mode adds optional narration and background music to an existing video.
- Added a shared source video volume control from 0% mute through 100% original level to 200% gain.
- Media Export now supports outputs from all three Media Composition modes.

## New Features

- Media Composition ports change dynamically for image collections, video collections, or a single video.
- Changing modes safely identifies and removes incompatible visual connections after confirmation.
- Video modes preserve and mix original source audio where available and handle silent clips or missing source audio.
- Optional narration and background music are supported in both video modes.
- Video-mode audio timelines are finite and aligned to the composed video duration.
- Mode-aware validation and retry controls expose only settings that apply to the selected composition mode.
- The UI hides image timing controls in video modes and hides transition controls in Single video mix mode.
- Generated-media regression coverage now exercises video sequence and single video mix exports.

## Fixes

- Fixed Media Composition and Media Export failures involving looped background music and FFmpeg finalization.
- Fixed Single video mix export when background music is connected.
- Media Export now accepts image slideshow, video sequence, and single video mix compositions.
- Existing image slideshow pipelines remain backward compatible.

## Known Limitations

- There is no full timeline editor.
- There is no audio-only Media Composition mode.
- Video modes re-encode through FFmpeg.
- Source video gain above 100% can clip because no limiter is currently applied.
- There are no separate per-clip source audio controls beyond the shared source video volume.
- The existing Vite large-chunk warning may still appear.
- Other hardware and provider-dependent areas remain listed in the [README untested-features section](../README.md#untested-features-as-of-v0470).

## Download

1. Open the Assets section below.
2. Download `LocalAIHub-Setup-0.47.0.exe`.
3. Run the installer and follow the Windows instructions.

The `.exe` is the installer. The `.blockmap` and `latest.yml` files support the application's release/update flow and normally should not be downloaded or opened manually.

## Windows SmartScreen and Unsigned Installer

Local AI Hub is currently distributed as an unsigned Windows app. Windows SmartScreen, browsers, or antivirus software may warn before the installer runs.

Download the installer only from the official Local AI Hub GitHub release. If SmartScreen appears, choose `More info`, verify that the file is the release asset you intended to download, and select `Run anyway` only if you trust the source and want to continue.
