# Local AI Hub v0.52.0

## Support and Docs

- Added GitHub issue templates for bug reports, feature requests, and troubleshooting/support requests.
- Added troubleshooting documentation with diagnostics-bundle guidance.
- Added lightweight CONTRIBUTING.md.
- Updated README help, diagnostics, and support links.

## Pipeline and Tool Integration

- Made Whisper's pipeline strategy explicit while preserving existing audio-to-text behavior.

## Model Manager

- Fixed duplicate installed-model inventory from shared model directories.
- Fixed CivitAI LoRA/accessory classification when file.type is generic.
- Added identity-aware conflict blocking for same-filename/different-source models.
- Added download locking and Model Manager busy state.
- Fixed Ollama streamed-error handling.
- Fixed Wan shard completeness validation.
- Fixed partial package reconciliation so incomplete packages are marked damaged/incomplete instead of installed.
- Added trusted transfer size and SHA-256 verification where metadata is available.
- Added InvokeAI staging and final-destination disk preflight checks.
- Tightened .pt/.pth upscaler classification.
- Added realpath/reparse-point containment hardening.
- Added bounded directory scanning.
- Added preview URL allowlist and sanitization.
- Added local inventory cache and bounded provider caches.
- Added source/version/license/provenance metadata display.
- Added safe source/artifact links.
- Added explicit version/artifact picker.
- Added destination-conflict UI with plain-English guidance.
- Added focused Model Manager verifiers covering inventory, downloads, integrity, filesystem security, performance caches, and provenance selection.

## Known Limitations

- Download cancellation is planned separately and is not included in this release.
- Pause/resume downloads and local file import are not included.
- Hash verification only applies where trusted checksum metadata exists.
- Provider catalog data may be cached briefly.
- Preview allowlist is conservative and may hide unsupported preview hosts.
- Live provider-backed wizard validation was not run.
- Existing Vite large Pipeline chunk warning may still appear.
