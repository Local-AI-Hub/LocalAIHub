# Local AI Hub v0.38.0

Local AI Hub 0.38.0 focuses on reusable local media assets and stronger media pipeline export behavior.

## Highlights

- Added the Asset Library Manager foundation in Settings with exactly three local library types: Sound Effects, Fonts, and Color Palettes.
- Added preview polish for managed assets: sound effects can be previewed, imported fonts show sample previews, and color palette previews remain available through scoped localaihub-asset:// URLs.
- Added managed Sound Effects library support to Media Composition, including random interval, scene-aligned, and combined scheduling modes.
- Added multi-layer sound effects scheduling for Media Composition. Each layer has independent library selection, scheduling mode, volume, density, spacing, repeat avoidance, fade, and seed/settings.
- Kept sound effects resolved through managed libraries only, mixed them into Media Export audio, and avoided unexpectedly extending final export duration.
- Stabilized scene transitions by excluding the unstable squeezeh and squeezev FFmpeg xfade transitions after reproducing export failures, with improved diagnostics for transition/export errors.
- Added Burn Subtitles / Captions integration with imported Font libraries and Color Palette libraries for text, outline, and background colors.
- Kept built-in/manual font and color controls available, and extended validation retry overrides to support imported fonts and palette colors.
- Resolved imported fonts safely from managed libraries and provided them to FFmpeg/libass through a run-scoped fontsdir.
