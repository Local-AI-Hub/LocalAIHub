# v0.36.0 - Pipeline audio modes, composition controls, and safer outputs

## Highlights
- Fixes Model Step audio mode gating so AudioCraft only exposes Music, Sound, and Continuation, while Chatterbox-Turbo only exposes Reference Voice TTS.
- Normalizes invalid saved Model Step audio/tool combinations safely and fixes the renderer crash path.
- Aligns Pipeline Builder connection lines to the actual rendered port-dot centers for precise graph editing.
- Adds Copy Pipeline for duplicating saved pipeline definitions and configuration without copying outputs, run history, or artifacts.
- Adds media composition controls for narration and background music levels, preserving the previous defaults of 100% narration and 22% background music.
- Makes pipeline output deletion safer by defaulting to the Windows Recycle Bin / OS trash, with a setting for permanent deletion.
- Adds Chatterbox-Turbo collectionMap text-to-audio support for collection:text plus shared reference audio to collection:audio.

## Pipeline Builder
- Connection edges now track the rendered port dot centers instead of relying on approximate panel coordinates.
- Copy Pipeline creates a new saved pipeline copy while preserving the original definition and config.
- Copied pipelines intentionally do not duplicate generated outputs, run history, or artifact files.

## Audio and media workflows
- AudioCraft remains limited to Music, Sound, and Continuation modes.
- Chatterbox-Turbo remains limited to Reference Voice TTS and now appears as a collectionMap text-to-audio backend.
- Media composition exposes narration and background music mix levels for generated compositions.
- Existing media composition behavior is preserved when users leave the new levels at their defaults.

## Output deletion safety
- Pipeline output deletion sends primary outputs and recognized sidecars to the Windows Recycle Bin / OS trash by default.
- Users can opt into permanent deletion from settings.
- Collection and composition folder deletion paths are covered.
- Orphan sidecars are hidden from the output list.

## Verification
- Automated release validation passed for UI build, full Electron build, manifest verification, Model Step node behavior, audio pipeline behavior, collectionMap behavior, media utilities, output deletion, pipeline copy, and media composition.
- Manual validation confirmed the Model Step audio-mode fix, precise Pipeline Builder connection alignment, Copy Pipeline behavior, media composition mix levels, safer output deletion, and Chatterbox collectionMap audio collection generation.
