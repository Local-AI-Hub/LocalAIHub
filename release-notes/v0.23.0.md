# v0.23.0 - Specialized model assets, tool lifecycle hardening, managed temp/cache, and installer reliability

## Highlights

- Restores reliable app-wide text input focus after confirm/delete actions by routing confirmation through the Electron main process while retaining renderer diagnostics.
- Hardens Local AI Hub-managed temp/cache handling for child tools, including Python, Hugging Face, Torch, Gradio, and related cache roots plus disk-pressure preflight warnings.
- Improves Aider/Ollama process ownership so Local AI Hub cleans up only sessions it owns while preserving external Ollama instances.
- Expands Model Manager support for specialized model assets and package layouts across RVC, AudioCraft, Wan, and Upscayl.
- Removes Fooocus from active Store, Library, and manifest support while ignoring stale removed-tool config safely.

## Model Manager and specialized assets

- Adds RVC remote support for .pth/.pt voice weights with optional .index companions and improves RVC search behavior.
- Adds package and folder-layout Model Manager support for specialized assets.
- Adds AudioCraft package/snapshot support, runtime model refresh, and improved AudioGen/MusicGen package layout handling.
- Adds Wan package/folder support for video model assets.
- Adds Upscayl paired .param/.bin package support and clearer no-results guidance when remote discovery is intentionally conservative.
- Preserves sidecar and package metadata through repair so downloaded model assets remain identifiable.

## Tool install, repair, and runtime fixes

- AudioCraft install and repair now install local AudioCraft source into the virtual environment.
- AudioCraft import/readiness checks and structured error reporting are improved, and WAV export no longer depends on TorchCodec.
- Wan2.1 install/preflight no longer hard-blocks on CUDA Toolkit/nvcc when only optional flash_attn acceleration is affected.
- Improves optional flash_attn behavior, DiffSynth dependency handling, Wan launcher validation, and runtime readiness messaging.
- Corrects the Wan launcher path to the current upstream gradio/t2v_1.3B_singleGPU.py entrypoint.
- Keeps Model Manager assets through Repair while removing tool-associated assets on Uninstall.

## Pipeline and local tool reliability

- Adds managed cache and temp environment parity across Library and Pipeline launches.
- Adds owned Ollama session tracking, owned concrete PID cleanup, and external Ollama preservation.
- Improves Aider timeout, retry, and session error classification, with no Local AI Hub hard Aider session timeout.
- Continues verifier coverage for model download plans, audio, video, image transform, manifest, Aider/Ollama lifecycle, focus guard, and managed launch storage behavior.

## UI/input and Library polish

- Fixes stale "Local AI Hub updated ComfyUI/Open WebUI" messages so they no longer persist incorrectly.
- Prevents masked cloud provider API keys from overflowing into adjacent fields.
- Keeps renderer diagnostics available while avoiding raw stack traces in user-facing confirmation flows.

## Verification and known limitations

Validated in this release pass:

- Version metadata confirmed at 0.23.0 in package.json and package-lock.json.
- Release artifacts confirmed for 0.23.0: LocalAIHub-Setup-0.23.0.exe, LocalAIHub-Setup-0.23.0.exe.blockmap, and latest.yml.
- Tools manifest verification.
- Model download plan verification.
- Aider/Ollama lifecycle verification.
- Focus guard verification.
- Managed launch storage verification.
- Wan install/preflight verification.

Known limitations:

- Wan generation remains hardware-gated and is not realistically expected on GTX 1060-class hardware.
- Wan model packages may be large, and model availability/readiness remains separate from tool install.
- AudioCraft can still be slow or heavy depending on model and hardware.
- Upscayl remote discovery remains conservative; broad remote search is intentionally not faked.
- AudioCraft, Wan, and Upscayl package support is Hugging Face-first where implemented.
- Split GGUF bundles remain blocked.
- collectionMap is not yet generalized to all media operation families.
- Per-item validation/retry inside collectionMap is not implemented.
- A broader graph workflow preset registry remains future work.
