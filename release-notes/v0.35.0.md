# v0.35.0 - Media normalization, collection conversion, and local cooldowns

## Highlights
- Expands Normalize Audio conversion support for single audio artifacts and audio collections.
- Expands Normalize Video conversion support for single video artifacts and video collections.
- Adds Normalize Image for converting single images and image collections with sidecar metadata.
- Extends collection-aware normalization and conversion handling across pipeline media utilities.
- Adds an optional heavy local step cooldown system for long local pipeline runs.
- Ships with rebuilt `0.35.0` Windows installer artifacts and targeted release verification.

## Media normalization and conversion
- Normalize Audio now supports broader output conversion options while preserving the existing default behavior.
- Normalize Video now supports broader output conversion options while preserving the existing default behavior.
- Normalize Image supports deterministic image conversion for common local workflow formats.
- Normalization outputs continue to produce media artifacts with metadata sidecars so downstream nodes can inspect lineage and media details.
- Media conversion errors are reported as plain-English pipeline failures instead of raw tool traces where practical.

## Collection-aware workflows
- Audio, video, and image normalization can operate over compatible media collections.
- Collection outputs preserve item ordering, item metadata, and collection manifests.
- `collectionMap` support remains compatible with media normalization/conversion outputs.
- Existing collection handling, cancellation paths, partial results, and media sidecars were kept in scope for regression coverage.

## Heavy local step cooldowns
- Adds pipeline run settings for an optional cooldown between heavy local steps.
- Applies cooldowns to heavy local model work such as image, audio, and video generation/transform steps, including selected local graph workflow paths.
- Keeps deterministic media utility nodes out of direct heavy-step classification.
- Makes cooldown waits cancellable and records cooldown wait counts in run metadata.
- Carries repeat cooldown settings into AudioCraft continuation repeat execution.

## Verification and known limitations
- Release verification covered UI build, full Electron build, manifest signature verification, Model Step node behavior, audio pipeline behavior, collectionMap behavior, local video pipeline behavior, media utilities, Wan readiness, TripoSR/Trellis readiness, and heavy local cooldown behavior.
- The media normalization/conversion pass was manually tested and validated before release finalization.
- Wan full generation remains hardware-dependent and was not expanded beyond existing readiness coverage in this release.
- Cooldown settings are opt-in and default to off for new pipelines.
