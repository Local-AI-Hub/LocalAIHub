# Local AI Hub 0.56.0

- Added opt-in local agent access in Settings, a Claude Desktop MCP extension, and a CLI for local agent hosts.
- Agents can discover installed tools/models and pipeline nodes, create and save pipelines, start asynchronous runs, inspect progress, cancel, and retrieve saved text outputs or media paths.
- Added authenticated local connections, bounded requests, explicit overwrite controls, and session-scoped run request deduplication.
- Fixed a shared pipeline-start race so simultaneous UI and agent requests cannot both pass asynchronous preflight.
- Added automated service, transport, extension, CLI, and Settings render verification.

Agent access is disabled by default. Existing runs continue when access is disabled. Claude Desktop installation and actual host tool registration require manual verification; no GUI tests were run. See docs/agent-access.md for setup, permissions and current limits.
