# v0.22.0 - Model Manager reliability, unified Model Step, media operation polish, and pipeline UX cleanup

## Highlights

- Strengthens Model Manager artifact compatibility, repository result shaping, and download planning across Hugging Face, CivitAI, Ollama, Tabby, and GGUF sources.
- Unifies pipeline authoring around the Model Step, moves Graph Workflow into AI Steps, and removes older standalone Image Generation, Image Analysis, and Audio Transcription nodes from normal authoring.
- Improves local image, audio, and video operation parity, including shared backend selection, checkpoint identity handling, image transform parity, audio pipeline parity, and Wan 2.1/video metadata readiness.
- Cleans up pipeline outputs and sidebar run-state visibility, while hardening credential handling and renderer diagnostics.

## Model Manager and model assets

- Improves artifact compatibility filtering, selected-artifact clarity, and stale search result clearing.
- Hardens download planning and downloaded-state identity with sidecar metadata.
- Uses more conservative hardware-fit scoring for lower-end systems.
- Adds shared local image backend selection.
- Improves Forge/Automatic1111 checkpoint refresh, canonical checkpoint identity matching, and checkpoint override behavior.
- Improves RVC local voice-model discovery.
- Keeps Fooocus honestly gated as Library-launchable where available, but not pipeline-runnable.

## Pipeline Builder and Model Step

- Makes Model Step the unified AI operation node in normal pipeline authoring.
- Moves Graph Workflow into AI Steps and cleans up the workflow contract.
- Removes the old standalone Image Generation, Image Analysis, and Audio Transcription nodes from the normal authoring surface.
- Keeps ComfyUI graph workflows as the configured backend for compatible collectionMap operations rather than pretending ComfyUI is a generic A1111/Forge backend.

## Media operations

- Brings image transform behavior into parity for Upscayl and FaceFusion pipeline paths.
- Improves audio generation and audio transform parity for AudioCraft and RVC.
- Improves Wan 2.1/video-generation readiness and output metadata polish.
- Adds final-output metadata and filters internal/sidecar artifacts in Outputs.
- Keeps active pipeline run state visible in the sidebar while navigating the app.

## Wizard and Planner

- Improves capability exposure for audio generation, audio transform, video generation, and image transform.
- Improves Planner model ordering so Gemini 2.5 Flash appears in Planner model refresh.
- Continues Model Step-compatible graph generation.

## Security and diagnostics

- Adds environment-variable credential support through a shared credential resolver.
- Improves redaction and log handling so secrets are less likely to leak through provider/process diagnostics.
- Adds more durable renderer error logging for future UI crash diagnosis.

## Verification and known limitations

Validated in this release pass:

- Version metadata confirmed at 0.22.0 in package.json and package-lock.json.
- Release artifacts confirmed for 0.22.0: LocalAIHub-Setup-0.22.0.exe, LocalAIHub-Setup-0.22.0.exe.blockmap, and latest.yml.
- Tools manifest verification.
- Model download plan verification.
- Provider credential security verification.
- Model Step node verification.
- Pipeline image transform verification.
- Planner provider/model refresh verification.

Known limitations:

- Fooocus is still not pipeline-runnable.
- ComfyUI remains graph-native; it is not a fake Automatic1111/Forge-style backend.
- collectionMap is not yet generalized to all media operation families.
- Per-item validation/retry inside collectionMap is not implemented.
- Split GGUF bundle installs remain blocked until multi-file model download support exists.
- Wan/local video generation remains hardware-gated and is not realistically runnable on GTX 1060-class hardware.
- Older saved pipelines that still depend on deleted standalone node types may need manual rebuild or migration.
