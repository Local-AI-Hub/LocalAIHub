# v0.29.0 - Structured audio planning, AudioCraft chaining, and generated-song templates

## Highlights

- Adds structured audio prompt planning from a plain text idea into ordered section prompts.
- Extends AudioCraft continuation so one source clip can continue multiple times in a single run.
- Adds stateful local AudioCraft sequential continuation for collectionMap text-to-audio workflows.
- Adds an Audio Stitch node and a generated-song starter template that can turn an idea into one WAV output.
- Ships with rebuilt `0.29.0` Windows installer artifacts and targeted release verification.

## AudioCraft repeat-continuation

- Model Step AudioCraft Continuation now supports repeat count.
- Repeat count `1` preserves the previous behavior.
- Append-source mode produces one longer file containing the original source plus repeated continuation segments.
- Continuation-only mode outputs stitched generated continuation segments only.
- Metadata and sidecars record repeat count, per-repeat details, source duration, generated duration, final duration, and continuation settings.

## Audio prompt planning

- Adds the `audioPromptPlan.v1` planning schema for text idea to structured audio/music section plans.
- Converts `audioPromptPlan` output into an ordered `collection:text` audio prompt collection.
- Preserves section metadata such as name, duration, negative prompt, mood, energy, continuity notes, and transition notes.
- Adds the "Audio idea to audio prompt collection" template.
- Planner runtime now requests structured JSON for planning schemas where supported, including Gemini 2.5 Flash.
- Existing longform and scene planning behavior remains intact.

## Stateful AudioCraft collection mapping

- `collectionMap` text-to-audio now supports local AudioCraft Sequential continuation chain mode.
- Independent clip generation remains the default behavior.
- Sequential mode uses the prior or cumulative audio as the continuation source for later prompt items.
- Each section prompt is still applied individually.
- Outputs remain an ordered `collection:audio` of generated section segments.
- The final cumulative WAV path is recorded in collection manifest metadata.
- Per-item validation, retry, and partial-success behavior remain honest: previously accepted items are not rerun, and partial mode stops at the failed chain item while preserving successful segments.

## Audio Stitch and generated-song template

- Adds the Audio Stitch node under Flow.
- Converts ordered `collection:audio` clips into one concatenated WAV.
- Supports optional `gapSeconds` between clips.
- Metadata and sidecars record source collection, ordered clip refs, per-clip durations, total duration, and gap seconds.
- Uses conservative PCM WAV handling; mismatched formats fail clearly instead of producing bad audio.
- Adds the "Audio idea to generated song" template: Text Input -> Planning Packet -> Planner `audioPromptPlan` -> Plan Text Collection -> `collectionMap` text-to-audio with AudioCraft sequential continuation -> Audio Stitch -> Audio Output.
- The generated-song template leaves planner provider/model, AudioCraft model/settings, prompt style, and duration settings configurable.
- Existing media composition and video workflows are unchanged.

## Build hygiene

- Adds a `.gitattributes` source/binary line-ending policy.
- Splits pipeline templates into a separate Vite chunk.
- Removes the Vite chunk-size warning.
- One harmless LF/CRLF warning for `PipelineBuilderPanel.jsx` remains intentionally deferred to avoid a large line-ending-only churn pass.

## Verification and known limitations

- Targeted release verification covered audio prompt planning, audio pipeline behavior, collectionMap behavior, pipeline templates, pipeline planning, Model Step behavior, and the UI production build.
- Audio Stitch currently expects matching PCM WAV clip formats; mismatches fail with a clear plain-English message.
- `collectionMap` sequential continuation is currently local AudioCraft-focused, not a cloud audio behavior.
- The final combined WAV path from sequential `collectionMap` is metadata; the explicit Audio Stitch node is the supported way to turn `collection:audio` into a final audio artifact.
- The audio planning schema produces prompts and metadata; it does not itself generate audio.
- Automated text-to-video planning and collectionMap work remains future work.
- One LF/CRLF warning may remain for `PipelineBuilderPanel.jsx` and is intentionally deferred.
