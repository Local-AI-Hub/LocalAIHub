# Local AI Hub 0.62.1

- Import an existing local HyperFrames project using Import Folder in Managed projects or the MCP operation `hub_import_hyperframes_project`. The importer copies the project into managed storage and returns its project ID. The renderer and importer skip the root-level HyperFrames output directory `renders/`.
- Project checks distinguish JavaScript comments, namespace declarations and object keys from asset references. Rejected references identify the project-relative file, line and host or data-URL category.
- HyperFrames lint now sees linked timeline registrations and static CSS font-family variables while keeping vendor libraries external. The renderer preserves linked scripts and CSS font overrides and uses locally available fonts without downloading Google Fonts.
- MCP discovery lists supported HyperFrames quality and FPS values. Invalid values produce the same actionable error during validation and saving. HyperFrames diagnostics include recent pipeline failures.
