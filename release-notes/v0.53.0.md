# Local AI Hub v0.53.0

## Highlights

- Added managed HyperFrames support for local HTML/CSS/JS video composition workflows.
- Added a HyperFrames Render pipeline node for trusted local projects.
- Added managed HyperFrames projects, templates, blank projects, editor, assets, and render-to-MP4 flow.
- Added Model Manager download cancellation.
- Added Model Manager diagnostics and support health.
- Removed the known large Pipeline Builder chunk warning.

## HyperFrames

- Added HyperFrames as a managed local tool pinned to `hyperframes@0.6.112`.
- Added Node.js 22+ and npm preflight.
- Added managed Chrome Headless Shell provisioning under Local AI Hub managed storage.
- Added a managed FFmpeg and FFprobe runtime contract.
- Added a HyperFrames Render node supporting Project Input or File Input through MP4 Video Output, lint-before-render, FFprobe validation, cancellation, timeouts, one worker, and disabled browser GPU acceleration.
- Added managed projects under Local AI Hub managed storage.
- Added Animated Title Card, Lower Third / Caption, and Kinetic Text Scene starter templates.
- Added Blank Project / From Scratch creation.
- Added a safe composition editor for `.html`, `.css`, `.js`, `.md`, and `.txt` files.
- Added a local asset browser and import flow for supported images, audio, video clips, and fonts.
- Added local-only safety checks that block obvious HTTP, HTTPS, and data URL references.
- Added project health checks and project-to-pipeline handoff.
- Added temporal template verification so starter templates render real animation.

## Model Manager

- Added active download cancellation with a safe tool/download keyed API and UI.
- Added cancellation cleanup, locking, and cache handling.
- Preserved package folders and pre-existing files during cancellation.

## Diagnostics and support

- Added sanitized Model Manager health to diagnostics bundles.
- Added bounded local support failure summaries.
- Improved repair, install, launch, and readiness guidance to point users to Support and Diagnostics.
- Updated troubleshooting documentation, support text, and issue templates.

## Build and performance

- Split the heavy Pipelines bundle surface.
- Eliminated the known Vite `PipelineBuilderPanel` large-chunk warning.

## Known limitations

- HyperFrames Studio is not included in this release.
- HyperFrames live preview and AI-assisted authoring are not included.
- HyperFrames supports managed local projects and local assets only.
- Remote HTTP, HTTPS, and data URL references are blocked in the current render and editor flow.
- Arbitrary external project import is not included.
- Node.js 22+ and npm must already be installed by the user.
- The first HyperFrames setup or render may download browser/runtime components and requires available disk space.
- Studio feasibility identified telemetry, remote-resource, and broad API-surface concerns that require a later restricted/offline contract.
- Live provider-backed Pipeline Wizard validation was not run because it is opt-in and consumes provider quota.
