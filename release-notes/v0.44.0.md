# Local AI Hub v0.44.0

Local AI Hub 0.44.0 adds safer pipeline output cleanup and refreshes Starter Templates with clearer categories and new local AI workflows.

## Highlights

- Pipeline output deletion now includes an optional checkbox to clean up intermediate generated files from the same run.
- Users can delete only the selected saved output, or also remove generated images, audio, plans, composition artifacts, exports, manifests, and sidecars from that run.
- Cleanup respects the existing Recycle Bin or permanent delete setting.
- Run-level cleanup safely removes an empty pipeline run when no saved outputs remain, while preserving sibling outputs and files outside the run.
- Deletion previews now report file counts and sizes, and partial cleanup failures are explained in plain English.
- Removed redundant Starter Templates and retained the more complete workflows.
- Added the Voice cloning with Chatterbox template.
- Added the Face swap with FaceFusion template.
- Starter Templates are now grouped into exactly four categories: Text, Image, Audio, and Video, with template search.
- Updated the Voiceover slideshow video template with optional background music and review/retry flow.
- Updated the README untested-features heading for v0.44.0 while preserving the existing untested feature list.
