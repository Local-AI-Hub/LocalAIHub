# Local AI Hub v0.51.0

Local AI Hub 0.51.0 completes a maintenance cleanup after Window Settings unification and refreshes the project documentation with current application screenshots.

## Highlights

- Removed the legacy Settings IPC and preload methods for close behavior, live resource polling, and pipeline output deletion.
- Kept `saveWindowSettings` as the sole save path for Window behavior settings.
- Tightened fullscreen and Window Settings verifier coverage to reject the removed legacy methods, channels, and renderer calls.
- Preserved existing user-facing Window Settings behavior; this maintenance cleanup does not change how the controls work.
- Updated the README with nine current screenshots, including Home, Recorder, Pipelines Build, and Pipelines Outputs.
- Updated the README Feature Overview to include Recorder.
- Updated the landing page hero to use the Home screenshot beneath the main hero text.
- Reduced the landing page screenshot gallery to Pipelines Build, Model Manager, Recorder, and Library.
- Kept the demo video update separate from this release.

## Validation

Release validation includes the production UI build, Windows package build, manifest and launch-mode checks, the requested offline verifier suite, available media regression, asset-library, and prompt-style checks, static landing-page validation, README image/link validation, and `git diff --check`.

Live provider-backed Pipeline Wizard validation was intentionally not run because it is an opt-in check that can consume provider quota.

## Known Limitations

- No demo video embed is included yet.
- Live provider-backed wizard validation was not run for this release.
- The existing Vite large Pipeline chunk warning may still appear.
- The existing Whisper integration audit note may still exist if unchanged.

## Download

1. Open the Assets section below.
2. Download `LocalAIHub-Setup-0.51.0.exe`.
3. Run the installer and follow the Windows instructions.

The `.exe` is the installer. The `.blockmap` and `latest.yml` files support the application's release and update flow.

## Windows SmartScreen and Unsigned Installer

Local AI Hub is currently distributed as an unsigned Windows app. Windows SmartScreen, browsers, or antivirus software may warn before the installer runs.

Download the installer only from the official Local AI Hub GitHub release. If SmartScreen appears, choose `More info`, verify that the file is the release asset you intended to download, and select `Run anyway` only if you trust the source and want to continue.
