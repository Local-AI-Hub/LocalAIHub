# Local AI Hub 0.54.1 (local build, not published)

- Added an opt-in webcam framing preview before capture and a live preview while recording. Recording previews use the same FFmpeg camera input, with a separate 5 FPS JPEG output.
- Added DirectShow video-mode probing before webcam capture. The recorder selects a format supporting the requested rate, recognizes nominal 30/60 FPS choices backed by 29.97/59.94 FPS hardware, and explains unsupported rates before creating a recording. It prefers supported modes up to 720p to limit capture overhead.
- Added verified Qt Installer Framework headless uninstall handling for maintenance-tool based installers such as GPT4All. Existing vendor quiet commands and other uninstallers retain their behavior; the existing post-uninstall checks still determine completion.
- Expanded the external-AI HyperFrames verifier to render an independently authored scene instead of testing only the bundled scaffold. Test staging now stays inside temporary test storage.

Validation on November 10, 2026:

- UI build passed. Installer packaging used the existing, matching keytar 7.9.0 native binary from the installed 0.54.0 app after the standard native rebuild was blocked by cache/network permissions. The native module was loaded successfully without reading or writing credentials.
- HyperFrames authoring scaffold: 1280x720, 4 seconds, 30 FPS; restricted Studio lint and visible frame differences passed.
- Independently authored external-AI scene: 1280x720, 6 seconds, 30 FPS; service save/prepare/render flow, unchanged source files, invalid-code rejection, and visible frame differences passed. Sampled frames were visually inspected.
- Recorder lifecycle and real FFmpeg synthetic-video tests passed. Webcam-only and webcam-plus-microphone outputs retained 120 video frames at 60 FPS over 2 seconds while emitting 10 preview frames. Audio stream mapping was checked.
- Qt IFW, vendor quiet command, non-Qt fallback, MSI, and uninstall failure tests passed.
- Capability uninstall, manifest, launch modes, asset libraries, focused media regressions, and HyperFrames project/runtime/editor/render/safety contract verifiers passed.

Remaining limitations:

- Physical camera frame-rate support was not determined: command-line capture enumeration returned no devices.
- Desktop smoke testing was attempted but blocked: app accessibility text was readable, clicks failed with missing coordinate geometry, and window screenshots timed out even after rebinding the window.
- GPT4All's actual uninstall was not completed or verified on the host. Its installed Qt maintenance tool's help output confirmed headless purge support; its prior uninstall log ended at maintenance-tool launch.
- No release was published and no commit was pushed.

User verification after installing 0.54.1:

- Live webcam preview worked at a supported frame rate.
