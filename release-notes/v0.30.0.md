# v0.30.0 - Video prompt planning, text-to-video mapping, and FFmpeg media utilities

## Highlights

- Adds structured video prompt planning from scripts, text ideas, and concepts into ordered video prompt collections.
- Adds `collectionMap` text-to-video support with independent clips and local Wan-focused sequential previous-last-frame chaining.
- Adds Video Stitch for combining ordered compatible MP4 clips into one final video artifact.
- Adds FFmpeg-backed media utility nodes for extracting frames/audio, normalizing collections, trimming media, and burning subtitles.
- Reorganizes media pipeline nodes into a clearer Deterministic Media Operations palette section.
- Ships with rebuilt `0.30.0` Windows installer artifacts and targeted release verification.

## Video planning and text-to-video collection mapping

- Adds the `videoPromptPlan.v1` planning schema.
- Adds the "Script to video prompt collection" template.
- Converts text, scripts, and concepts into ordered `collection:text` video prompt plans.
- Preserves metadata such as duration, camera motion, subject motion, setting, action, negative prompt, continuity notes, transition notes, reference-frame intent, and source text.
- Registers structured JSON planner requests for the video planning schema.
- Adds `collection:text` to `collection:video` mapping.
- Keeps independent text-to-video clips as the default mode.
- Adds local Wan-focused sequential previous-last-frame chaining so later clips can use the previous accepted clip's extracted last frame as a reference image.
- Preserves prompt styles, per-item validation/retry behavior, partial success, ordering, lineage, and metadata.
- Reports readiness and errors honestly for missing Wan installs, missing models, hardware constraints, unsupported cloud chaining, invalid sizes, or missing references.

## Video Stitch and generated-video template

- Adds the Video Stitch node for `collection:video` to `video` workflows.
- Concatenates ordered MP4 clips into one final video artifact.
- Records source collection, item refs, prompts, fps and size metadata where available, chain metadata, concat mode, and created-by info.
- Uses conservative MP4 concat-compatible handling so mismatched or non-MP4 clips fail clearly.
- Adds the "Video idea to generated video" template: Text Input -> Planning Packet -> Planner `videoPromptPlan` -> Plan Text Collection -> `collectionMap` text-to-video -> Video Stitch -> Video Output.
- Keeps the planning-only "Script to video prompt collection" template available.

## FFmpeg media utilities

- Adds Extract Video Frame for `video` to `image`, with first-frame and last-frame modes.
- Adds Extract Audio for `video` to `audio`.
- Adds Normalize Audio Collection for `collection:audio` to `collection:audio`.
- Adds Normalize Video Collection for `collection:video` to `collection:video`.
- Adds Trim Media for audio and video, with clearer Start time, End time, and Duration seconds UI plus direct typed decimal input.
- Adds Burn Subtitles / Captions for `video` plus captions, transcript, or subtitle input to `video`.
- Burn Subtitles supports timed transcript segments, subtitle files where feasible, and manual text lines using `durationPerCaptionSeconds`.
- Media utility nodes use FFmpeg through shared safe argument-array execution and preserve sidecar metadata.

## Palette organization

- Adds the Deterministic Media Operations palette section.
- Moves media operation nodes into that section: Audio Stitch, Video Stitch, Media Composition, Media Export, Extract Video Frame, Extract Audio, Normalize Audio Collection, Normalize Video Collection, Trim Media, Burn Subtitles / Captions, and Collection Builder.
- Moves Map Collection and Validation into AI Steps.
- Renames display labels: Image File to Image Input, Audio File to Audio Input, and Video File to Video Input.
- Leaves node type IDs unchanged for saved-pipeline compatibility.

## Verification and known limitations

- Targeted release verification covered video prompt planning, local video pipeline behavior, media utilities, collectionMap behavior, pipeline templates, media composition, Model Step behavior, audio pipeline behavior, and the UI production build.
- `collectionMap` text-to-video runtime was not manually tested on this GTX 1060-class hardware.
- Sequential previous-last-frame chaining is local/Wan-focused; cloud reference-image chaining was intentionally not implemented.
- Actual local video generation was not claimed or tested on unsupported hardware.
- Video Stitch currently expects compatible MP4 clips and fails clearly on mismatches.
- Normalize nodes output normalized collections; they do not stitch or combine media.
- Burn Subtitles advanced styling and font controls are deferred.
- Split Video Into Clips was intentionally not implemented.
- One harmless LF/CRLF warning for `PipelineBuilderPanel.jsx` may remain intentionally deferred.
