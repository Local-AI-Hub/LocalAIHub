# v0.26.0 - Dense UI redesign, AudioCraft continuation, partial collection outputs, and persisted Statistics index

## Highlights

- Completes the main no-scroll UI density pass across the Library, Store, Model Manager, Statistics, Settings, and Pipelines surfaces.
- Adds real AudioCraft continuation support for Model Step audio generation, including continuation-only and source-plus-continuation output modes.
- Adds explicit partial-success behavior for collectionMap outputs while keeping all-or-fail behavior available.
- Adds a persisted local Statistics index so repeated storage/model/tool sizing can avoid unnecessary full rescans.

## UI density and layout improvements

- Compacts tab headers, resource strips, Library cards, Store cards, provider cards, and tool update cards.
- Gives Model Manager denser controls plus internal scroll regions for downloaded models and remote catalog results.
- Converts Statistics, Settings, and Pipelines into compact contained panels with internal scrolling where needed.
- Makes the Pipeline setup/control box collapsible within the Pipelines section system.
- Adds taskbar-safe bottom reserve and clean-bottom scrolling fixes so dense views do not hide controls at the bottom of the window.

## AudioCraft continuation

- Adds AudioCraft continuation using source audio and last-N-seconds seed behavior.
- Supports continuation-only output and source-plus-continuation append mode.
- Exposes stable AudioCraft advanced settings including temperature, top_k, top_p, cfg coefficient, and two-step CFG.
- Preserves PCM WAV export fallback behavior.
- Records source, seed, generated duration, final duration, append-source mode, model, and generation settings in metadata and sidecars.

## CollectionMap partial success

- Adds an explicit failure behavior option for partial collection output.
- Allows successful items to be preserved when later items fail.
- Marks partial collections clearly as partial.
- Preserves failed item metadata and attempt metadata for reporting and follow-up.
- Keeps default all-or-fail behavior available for workflows that require strict completion.

## Statistics index and performance

- Adds local `statistics-index.json` persistence for Statistics sizing data.
- Uses indexed storage, model, and tool size data on repeated loads when fresh.
- Adds section-level freshness checks and invalidation.
- Supports manual refresh/rebuild behavior.
- Adds invalidation hooks for relevant local lifecycle events.
- Adds timing diagnostics for index hit, miss, and rebuild paths.

## Verification and known limitations

- Verified manifest signature, audio pipeline behavior, media composition, model download plans, provider credential handling, Model Step behavior, collectionMap behavior, and Statistics index behavior for this release.
- Full Graph Workflow preset registry remains future work.
- The Statistics index improves repeated loads but can still rebuild when invalidated or stale.
- UI density may still receive visual polish later, but this release completes the main no-scroll redesign pass.
- AudioCraft continuation is Model Step-focused; collectionMap continuation remains intentionally unimplemented because per-item source-audio semantics are ambiguous.
- collectionMap partial success does not silently accept failed items; failed items remain excluded and reported.
- Wan generation remains hardware-gated and is not realistically expected on GTX 1060-class hardware.
