# Local AI Hub v0.49.0

Local AI Hub 0.49.0 adds a new Home experience, safer support diagnostics, GitHub Releases update checks, and several focused workspace improvements.

## Highlights

- Added Settings -> Support and Diagnostics.
- Added Copy system info for safe support summaries.
- Added diagnostics bundle generation with sanitized logs, app summary, tool and provider summaries, recorder summaries, pipeline summaries, and config summary.
- Diagnostics explicitly exclude secrets, model files, source media, generated outputs, recorder media, and pipeline artifacts.
- Added Settings -> Updates with GitHub Releases update checks.
- Added current and latest version display, release notes, installer download link, and a check-on-launch toggle.
- Added Home as the app launch page.
- Added a Getting Started checklist and quick actions.
- Added a collapsible global sidebar with a compact top-left Expand sidebar control.
- Fixed the Pipelines expanded Outputs layout.
- Removed the duplicate Home hardware card.
- Added a collapsible Recorder Managed Storage section.
- Added internal tool integration contract documentation.
- Added a lightweight internal tool integration contract verifier.

## Validation

Release validation includes the full offline build and verifier set documented for 0.49.0. Live provider-backed Pipeline Wizard validation and live Groq planner testing are intentionally excluded because they are opt-in, quota-consuming checks.

## Known Limitations

- Update checks are metadata and link based; Local AI Hub does not silently execute an installer in-app.
- Users should still review diagnostics bundles before sharing them.
- The internal tool integration contract is not a public plugin SDK.
- The contract audit documents known integration gaps but does not migrate the tool architecture.
- There is no Settings option to reset a dismissed Home checklist.
- The existing Vite large-chunk warning may still appear.

## Download

1. Open the Assets section below.
2. Download `LocalAIHub-Setup-0.49.0.exe`.
3. Run the installer and follow the Windows instructions.

The `.exe` is the installer. The `.blockmap` and `latest.yml` files support the application's release and update flow.

## Windows SmartScreen and Unsigned Installer

Local AI Hub is currently distributed as an unsigned Windows app. Windows SmartScreen, browsers, or antivirus software may warn before the installer runs.

Download the installer only from the official Local AI Hub GitHub release. If SmartScreen appears, choose `More info`, verify that the file is the release asset you intended to download, and select `Run anyway` only if you trust the source and want to continue.
