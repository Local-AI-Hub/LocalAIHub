## Local AI Hub v0.16.0

- Stabilization release focused on remaining launch and runtime edge cases.
- Improves updater reliability and release metadata alignment for Windows installs.
- Tightens runtime failure classification so Local AI Hub reports launch boundaries more accurately instead of mislabeling them as install or bootstrap failures.
- Automatic1111 may still fail on some Windows hardware or native runtime combinations after checkpoint load; when that happens, Local AI Hub now surfaces the boundary more honestly instead of overstating what it can repair automatically.

Known issues:
- Automatic1111 is not yet reliable across all supported Windows GPU and runtime stacks.
