# Local AI Hub 0.57.0

- Added agent discovery of configured provider capabilities, saved prompt/workflow presets, and starter templates without contacting cloud providers.
- Added saved-media metadata and JPEG image/video-frame previews returned as native MCP image content. Audio inspection supplies metadata, not playback.
- Added bounded, redacted tool runtime log tails and asynchronous launch/stop jobs with session-scoped request deduplication.
- Added a shared execution guard between pipeline starts and agent lifecycle actions.
- Fixed plain text outputs incorrectly receiving a Transcript summary label.
- Included the confirmed hosted-runtime MCP startup fix in the bundled extension. Hub and extension versions are 0.57.0; replace the Claude Desktop extension to discover all 19 tools.
- Improved CLI errors to distinguish a blocked local connection from an unavailable app.

Automated verification covers discovery, redaction, media decoding, managed-path/junction containment, MCP image transport, lifecycle jobs, cancellation, shared execution guards, CLI, extension startup and Settings render. No GUI automation was used.

Live CLI testing against the user's running Hub was blocked by Windows EPERM on its named pipe in the agent execution sandbox. No successful live local-model test is claimed. scripts/test-agent-live.js provides the opt-in text and local-model workflow test; it never downloads a model, uses a cloud model, or interrupts an existing run.
