# Local AI Hub v0.50.0

Local AI Hub 0.50.0 adds persistent fullscreen and windowed modes, reorganizes Pipelines into focused workspace subviews, and improves navigation and editing throughout the Pipeline workspace.

## Highlights

- Added true fullscreen and windowed screen mode support.
- Added Settings -> Window behavior mode selection with Windowed mode and Fullscreen mode.
- Added persisted screen mode so the saved fullscreen or windowed preference applies on relaunch.
- Added an F11 runtime fullscreen toggle.
- Added unified Save window settings behavior for screen mode, close behavior, background resource polling, and pipeline output deletion behavior.
- Added a separate Close Local AI Hub button to the expanded sidebar.
- Close Local AI Hub preserves the existing close-to-tray and safe-close behavior.
- Added Pipelines workspace subviews for Get Started, Build, Resources, and Outputs.
- Pipelines now opens to Get Started by default from the sidebar.
- Home Pipeline quick actions now route to the appropriate Pipelines subview.
- Moved Asset Libraries from Settings to Pipelines -> Resources.
- Moved Prompt Style Presets from Settings to Pipelines -> Resources.
- Added a contextual Node Inspector overlay in Build with right-click, double-click, Escape, and outside-click behavior.
- Preserved collapsible Pipeline sections while reducing workspace tab clutter.
- Pipeline Outputs now occupies the full subview width by design.
- Added focused fullscreen and window controls verification.
- Added focused Pipelines workspace subviews verification.

## Validation

Release validation includes the full offline build and verifier set documented for 0.50.0. Fullscreen persistence, windowed persistence, F11 runtime toggling, safe close and tray behavior, Pipelines subviews, resource relocation, the contextual Node Inspector, full-width Outputs, Home quick actions, Recorder, Settings, sidebar persistence, and Pipelines were also manually validated.

Live provider-backed Pipeline Wizard validation was intentionally not run because it is an opt-in, quota-consuming check.

## Known Limitations

- No floating fullscreen control is shown by design; use Settings or F11 to change mode.
- F11 changes runtime mode only. Click Save window settings to persist the selected screen mode.
- The Pipeline workspace redesign changes UI organization only; it does not change pipeline execution semantics.
- Live provider-backed wizard validation was not run for this release.
- The existing Vite large Pipeline chunk warning may still appear.

## Download

1. Open the Assets section below.
2. Download `LocalAIHub-Setup-0.50.0.exe`.
3. Run the installer and follow the Windows instructions.

The `.exe` is the installer. The `.blockmap` and `latest.yml` files support the application's release and update flow.

## Windows SmartScreen and Unsigned Installer

Local AI Hub is currently distributed as an unsigned Windows app. Windows SmartScreen, browsers, or antivirus software may warn before the installer runs.

Download the installer only from the official Local AI Hub GitHub release. If SmartScreen appears, choose `More info`, verify that the file is the release asset you intended to download, and select `Run anyway` only if you trust the source and want to continue.
