# Local AI Hub 0.62.0

- MCP agents can preview and resolve pending image reviews on runs they started. Reviewed image maps accept per-item prompt and seed changes and preserve accepted items.
- Chatterbox narrates long scripts in a single model session, with configurable passage pauses and target duration. Its Model Step exposes timed captions for subtitle export or burn-in.
- AudioCraft reports loading, backend device, generation steps and elapsed time during generation.
- Scene-aligned sound effects can reuse a library's only effect. Composition status reports requested and scheduled accents and records skipped boundaries.
- Video export reads precise stream durations, conforms the picture to the output frame grid and checks the encoded frame count for fixed-length exports.
- HyperFrames Compose supports an illustrated layout with per-scene focus, start and end zoom, and numeric line, circle and rectangle overlays.
