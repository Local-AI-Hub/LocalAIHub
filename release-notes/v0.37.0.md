# v0.37.0 - Media validation retries, narration timing, and scene transitions

## Highlights
- Adds temporary Media Export mix retry controls when validating video artifacts produced from Media Composition.
- Adds temporary Burn Subtitles / Captions retry controls for burned-caption video artifacts.
- Fixes repeated burned-caption retry attempts so they use the original clean video source instead of the previously captioned output.
- Adds narration/transcript-driven image timing for longform visual planning and media composition.
- Keeps fallback seconds per image visible and configurable when dynamic timing is enabled.
- Adds optional scene transitions for slideshow/image compositions, including single-transition, random category, and random selected-list modes.
- Fixes the Media Export hang seen with dynamic timing plus transitions by bounding FFmpeg duration and passing cancel/timeout handling.

## Media validation retries
- Media Export validation now exposes temporary narration and background music level overrides for Media Composition artifacts.
- Retrying with those controls reruns Media Composition and Media Export with adjusted effective mix levels.
- Saved Media Composition configuration remains unchanged after retry overrides.
- Burn Subtitles validation now exposes temporary caption controls and reruns with adjusted effective caption settings.
- Saved Burn Subtitles configuration remains unchanged after retry overrides.

## Longform timing and transitions
- Longform scene plans now preserve start, end, duration, and narration timing metadata through Plan Text Collection and CollectionMap image collections.
- Media Composition supports fixed duration as well as dynamic narration/transcript timing for generated slideshow videos.
- Scene transition metadata is included in composition/export outputs.
- Transition selection is deterministic where needed and avoids immediate repeats.
