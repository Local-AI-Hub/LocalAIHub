# v0.24.0 - Collection Input, generalized collection mapping, and per-item validation/retry

## Highlights

- Adds a Collection Input node for manual typed collections across text, image, audio, video, and file items.
- Generalizes collectionMap beyond text-to-image into text, image, and audio mapping families with mapping-specific UI and config.
- Adds per-item validation and retry inside collectionMap for supported output kinds, preserving ordered output and item lineage.
- Cleans up collection capability inference, verifier coverage, runtime metadata, and Pipeline Builder bundle size.

## Collection Input

- Supports manual typed collections for text, image, audio, video, and file.
- Adds inline text item entry and file-backed item selection through the Windows file picker.
- Preserves item order and works with existing collection artifacts, Collection Output, and collectionMap.
- Fixes the text Add item renderer crash by moving shared collection input state handling into a reusable helper.

## Collection Map generalization

- Adds supported mappings for text to image, text to audio, image to image, audio to text, audio to audio, and image to text.
- Replaces stale text-to-image-only controls with mapping-specific UI and configuration.
- Refreshes relevant model selections for AudioCraft, RVC, Upscayl, Whisper, WebUI analysis modes, and Stable Diffusion checkpoints.
- Updates output metadata so collectionMap results reflect the actual mapping and operation.

## Per-item validation and retry

- Adds per-item LLM validation and retry for supported output kinds.
- Adds per-item manual User validation and retry using active run pause/resume.
- Retries only failed items instead of rerunning the entire collection.
- Preserves ordered output and lineage while recording attempt metadata.
- Fails fast after the configured maximum attempts with item index, item id, and the plain-English reason.

## Capability and build cleanup

- Fixes verify-pipeline-collections.js capability mismatch coverage.
- Updates Collection Builder and Accumulate output typing so typed collections are inferred from incoming item types instead of broad any-collection output.
- Resolves the Vite large chunk warning by safely lazy-loading PipelineBuilderPanel.
- Confirms Branch Merge remains required for mutually exclusive branch convergence and retry-loop re-entry.

## Verification and known limitations

Validated in this release pass:

- Version metadata confirmed at 0.24.0 in package.json and package-lock.json.
- Release artifacts confirmed for 0.24.0: LocalAIHub-Setup-0.24.0.exe, LocalAIHub-Setup-0.24.0.exe.blockmap, and latest.yml.
- Collection map verifier coverage.
- Collection input verifier coverage.
- UI production build.

Known limitations:

- collectionMap does not yet implement partial-success final outputs.
- LLM validation remains capability-honest; audio, video, and file LLM validation are not broadened without real evidence support.
- Manual per-item validation relies on active run pause/resume, not restart-persistent execution recovery.
- text/image-to-video and broader video/file collection mappings remain deferred.
- Graph workflow preset registry remains future work.
- Wan generation remains hardware-gated and is not realistically expected on GTX 1060-class hardware.
