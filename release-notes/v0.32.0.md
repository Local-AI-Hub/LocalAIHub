# v0.32.0 - Pagination, hover reveals, and card layout polish

## Highlights
- Added compact pagination controls across Library, Store, and the Model Manager remote catalog.
- Added integrated hover reveal behavior for known truncated descriptions and Pipeline Builder port labels.
- Normalized Library and Store card sizing so paginated pages fit cleanly without unnecessary internal scrolling.
- Completed an audit-only HyperFrames feasibility pass; no HyperFrames source integration is included in this release.

## Hover Reveal Polish
- Library tool cards, Store cards, and configured cloud provider cards now reveal full clamped descriptions on hover.
- Pipeline Builder node port labels now reveal full truncated labels/descriptions on hover.
- Reveal overlays use app-matching dark styling, avoid layout shift, and do not block card buttons or port dragging.

## Library, Store, And Model Manager Pagination
- Library pagination includes installed tools and configured cloud provider cards in one page flow.
- Store pagination applies after search and category filtering.
- Model Manager remote catalog pagination works over currently loaded remote results while preserving the existing Load More flow.
- Pagination resets or clamps when relevant search, source, tool, model, task, sort, or filter inputs change.
- Pagination controls sit near grid headers instead of at the bottom of long card grids.

## Normalized Card Sizing
- Library remains six cards per page with a stable 2-column by 3-row desktop layout.
- Store remains six cards per page with stable rows.
- Card metadata, descriptions, progress details, action rows, and status text clamp or truncate more consistently while preserving hover access to full text.
- Existing Launch, Stop, Settings, Uninstall, Official Uninstall, Repair, chat, console, transcription, change-model, snapshot, and install controls remain present and usable.

## HyperFrames Audit
- HyperFrames was reviewed for feasibility only.
- Recommendation: defer integration until a minimal Windows smoke test confirms Node 22, npm, FFmpeg, and Puppeteer rendering viability.
- If pursued later, HyperFrames should be treated as a managed Store/Library deterministic video composition and rendering tool plus render node, not as an internal bundled dependency or AI video backend.

## Verification And Known Limitations
- Verified with fast release-critical source checks and UI build checks for hover reveal behavior, pagination, model download plans, pipeline templates, model step nodes, and pipeline collection mapping.
- Model Manager remote catalog pagination is local pagination over loaded results; it does not force true provider-specific remote pagination.
- Hover reveal is applied to known truncated regions; it is not a global tooltip system.
- Cloud image-to-video and previous-last-frame chaining remain deferred because behavior is provider-specific.
- No new tools were added in this release.
