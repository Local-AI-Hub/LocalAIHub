# Local AI Hub v0.43.0

Local AI Hub 0.43.0 focuses on adaptive longform planner reliability for constrained models, stronger planner diagnostics, and safer OpenCode official desktop update reporting.

## Highlights

- Added adaptive longform planner chunk sizing so constrained planner models can reduce chunk duration before falling back deterministically.
- Added Groq GPT-OSS-120B longform planner rate-limit and backoff handling, including retry-after and TPM-window awareness.
- Improved longform planner per-chunk diagnostics with budget estimates, context profile selection, chunk split metadata, provider error categories, and rate-limit wait details.
- Reduced avoidable deterministic fallback for constrained planner models by splitting oversized planner requests and compacting rolling context.
- Fixed OpenCode official desktop update detection and reporting so validated official desktop updates no longer show the managed tools-folder guard.
- Expanded verifier coverage for adaptive chunk sizing, request-too-large splitting, rate-limit classification/backoff, bounded rolling context, OpenCode official desktop update detection, and README release-state tracking.
- Updated the README untested-features heading for v0.43.0 while preserving the existing untested feature list.
