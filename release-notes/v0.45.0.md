# Local AI Hub v0.45.0

Local AI Hub 0.45.0 adds a standalone Recorder for local screen, microphone, webcam, and system-audio capture.

## Highlights

- Added a standalone Recorder tab.
- Added full desktop screen recording and click-drag region capture.
- Added microphone-only and screen + microphone recording.
- Added webcam-only and webcam + microphone modes where webcam devices are available.
- Added Electron loopback capture for system audio only, selected display + system audio, and selected region + system audio.
- Added managed recordings storage with `.recording.json` sidecars.
- Added a recent recordings list with open, reveal, and delete actions.
- Added a tray Stop Recording action while recording is active.
- Recording deletion respects managed path safety and the configured Recycle Bin behavior.
- Added Recorder verifiers covering capture modes, storage safety, region selection, tray behavior, and deletion.
- Updated the README untested-features heading for v0.45.0 while preserving the existing untested feature list.

## Known Limitations

- Pipeline Builder does not yet include a Record Input node.
- The wizard does not yet support recorder nodes.
- Window capture is not available.
- Screen + webcam capture is not available.
- Combined system audio + microphone capture is not available yet.
- Hardware encoder selection is not available.
- System audio cannot be captured from arbitrary DirectShow loopback devices.
