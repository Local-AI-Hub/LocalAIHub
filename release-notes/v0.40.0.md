# Local AI Hub v0.40.0

Local AI Hub 0.40.0 focuses on safer dual-capability tool management, CUDA install hardening for ComfyUI, and expanded cloud/local media-generation pipeline coverage.

## Highlights

- Added safe dual-capability uninstall behavior for WebUI/Desktop tools so managed and companion installs can be removed without crossing capability boundaries.
- Hardened ComfyUI CUDA/PyTorch dependency setup and repair paths for more reliable NVIDIA installs.
- Added cloud image generation support in Model Step and collectionMap flows for OpenAI / ChatGPT, Google / Gemini, and xAI / Grok providers.
- Added Google Veo cloud video generation in Model Step and collectionMap flows.
- Added previous-last-frame chaining for Google collectionMap video generation.
- Added xAI / Grok Imagine cloud video generation in Model Step and collectionMap flows.
- Documented untested v0.40.0 features in the README so users can clearly distinguish automated coverage from real-world validation.
