# Local AI Hub 0.58.0

This release includes the accumulated changes developed in local builds 0.54.1 through 0.58.0.

## Recorder and tool management

- Added an optional webcam framing preview before recording and a live 5 FPS preview during recording, sharing the FFmpeg camera input.
- Probe webcam capture modes before recording, select a supported format, recognize fractional 29.97/59.94 FPS rates, and explain unsupported frame rates. Device probes time out with a plain-English error.
- Added verified Qt Installer Framework headless removal for maintenance-tool installers such as GPT4All, preserving vendor quiet commands and existing uninstall completion checks.

## HyperFrames pipelines

- Added HyperFrames Compose and a media-scenes starter template. Connect an image/video or ordered collection, optional scene-plan timing, narration, and transcript/SRT/VTT captions to produce a local project for HyperFrames Render and Video Output.
- Added composition settings for title, dimensions, scene duration, contain/cover framing, and gentle image motion. Validate media limits, ordered scene timing, narration length and caption timing; clean up canceled or failed compositions.
- Fixed scheduled zero-duration animation changes and forward/backward seeking so future scene and caption visibility changes do not apply prematurely.
- Moved the HyperFrames Library explanation and runtime details into card settings, and improved card scrolling and header visibility.
- Expanded automated authoring coverage with an independently authored external-AI scene and more reliable temporary-file cleanup.

## Local agent access and MCP extension

- Added opt-in Agent access in Settings, an authenticated local bridge, a dependency-free MCP server, CLI, and bundled Claude Desktop MCPB extension. Access is disabled by default.
- Added discovery of hardware, installed tools/models, node definitions, configured provider capabilities, saved presets and starter templates.
- Agents can draft, validate, save and run pipelines, poll or cancel runs, list saved outputs and read bounded text results. Overwriting saved pipelines requires an explicit flag. Session-scoped request IDs prevent duplicate runs on retries.
- Added asynchronous tool launch/stop jobs, readiness results, job polling, and bounded, redacted runtime diagnostics.
- Fixed simultaneous pipeline starts and added a shared guard between pipeline starts and agent tool lifecycle actions.
- Fixed MCP initialization when a host loads the server through require(), and improved CLI errors for blocked local connections.
- Added managed-output media metadata and native MCP JPEG image/video-frame previews, with bounded decoding and real-path containment checks.
- Fixed valid JPEG files that auto-detect as image2 by explicitly selecting the single-image JPEG reader.
- Added hub_deliver_media: native MCP audio content up to 700,000 bytes and temporary local browser playback/download links for full audio/video files, including byte-range streaming for seeking. Links expire after 30 minutes and are revoked when agent access stops. No media upload is performed.
- Fixed missing hardware context in shared pipeline validation and plain text outputs incorrectly labeled as transcripts.
- Added setup and scope documentation in docs/agent-access.md and docs/hyperframes-pipelines.md, plus automated service, transport, media, render and regression verifiers.

## Installation and scope

Install LocalAIHub-Setup-0.58.0.exe. Claude Desktop users must replace their installed extension with LocalAIHub-0.58.0.mcpb. Clients referencing the installed server.cjs directly need to restart their MCP connection after updating the Hub.

Agent access permits connected clients to read saved results and execute workflows using local inputs and configured providers, including paid cloud operations when selected. Results returned to a cloud client become part of its conversation. Disabling access revokes connections and media links but does not cancel already accepted pipeline or tool jobs.

Native in-chat audio playback and localhost link handling depend on the client and were not GUI-tested. Local playback/download links are not uploaded chat attachments. Browser codec support varies.

## Validation

Release-preparation verification passed:

- Agent access, hosted MCP startup, Settings render, media inspection/delivery, authenticated transport, request deduplication and lifecycle guards.
- HyperFrames composition, scheduled seeking, full pipeline regression coverage, scaffold/blank/external-AI renders, all three animated starter templates, trusted File Input, offline Studio and tool contracts. Render checks verified temporal frame differences and composition narration audio.
- Recorder lifecycle, synthetic 60 FPS webcam/video-plus-audio output with 5 FPS preview, Record Input and Windows uninstaller checks.
- Provider credential security using isolated temporary app-data storage; the initial attempt was blocked from writing the host log directory.
- Production UI build, MCPB creation and Windows installer packaging. Packaging reused the existing native dependencies with npmRebuild=false; the packaged keytar module loaded successfully without credential access. Packaged services, schema, animation runtime, agent clients and embedded MCPB matched source.
- Git whitespace checks and candidate-source scans for credential patterns and personal paths. Temporary verification output and agent connection descriptors are ignored. Test cache guards resolve the current home directory rather than embedding a username.

No GUI/computer-use smoke tests were performed. Live host model execution and in-chat playback were not retested during release preparation.
