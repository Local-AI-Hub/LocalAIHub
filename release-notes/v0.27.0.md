# v0.27.0 - Graph Workflow presets, Prompt Style presets, and UI polish

## Highlights

- Adds an app-local Graph Workflow preset registry for reusable workflow-backed pipeline nodes.
- Adds persisted Prompt Style Presets with deterministic final-prompt enforcement across key execution paths.
- Refines primary page widths, contained-page fit, and compact Pipeline layout behavior.
- Ships with rebuilt `0.27.0` Windows installer artifacts and targeted release verification.

## Graph Workflow preset registry

- Saves reusable Graph Workflow presets in app config.
- Lets Graph Workflow nodes save, select, and execute preset-backed workflows.
- Resolves preset workflow, bindings, tool, and contract data for analysis and execution.
- Keeps node-local Graph Workflow configuration working for existing pipelines.
- Allows collectionMap text-to-image steps to select compatible Graph Workflow presets.
- Filters or rejects incompatible presets instead of pretending they can run.
- Fixes renderer crash and preset save/list/dropdown regressions found during the release pass.

## Prompt Style Presets and deterministic enforcement

- Adds persisted Prompt Style Presets managed from Settings.
- Supports image, audio, video, text, and any-target filtering.
- Supports required terms, prefix/suffix text, negative prompt text, placement, dedupe, and exact-term enforcement.
- Applies styles at the final prompt execution boundary, not only through LLM instructions.
- Integrates style enforcement with Model Step text-driven image, audio, video, and text-response operations.
- Integrates style enforcement with collectionMap text-to-image and text-to-audio flows.
- Records original prompts, final prompts, style id/name, applied terms, and negative prompt merges in artifact metadata where relevant.

## UI polish and layout refinement

- Unifies primary page widths across the app.
- Improves contained-page bottom fit and reduces excessive blank space.
- Preserves taskbar-safe layout, internal scrolling, complete rounded bottoms, and no-scroll behavior.
- Compacts collapsed Pipeline section layout.

## Verification and known limitations

- Verified Graph Workflow orchestration, Prompt Style enforcement, Model Step behavior, collectionMap behavior, and UI build for this release.
- Wizard and Planner do not yet automatically select or propagate Prompt Styles.
- Pipeline-wide Prompt Style inheritance remains future work.
- Graph Workflow presets are stored in app-local config; this is not a marketplace or import/export system yet.
- collectionMap Graph Workflow preset support is conservative and focused on compatible text-to-image presets.
- Prompt Style enforcement is exact and deterministic, not semantic style reasoning.
- Wan generation remains hardware-gated and is not realistically expected on GTX 1060-class hardware.
