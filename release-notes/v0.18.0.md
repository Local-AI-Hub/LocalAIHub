## Local AI Hub v0.18.0

- Bounded pipeline/planning architecture release focused on making pipeline plans structured, reviewable, and easier to extend.
- Adds the Planning Packet / Planner / Plan flow as a first-class planning substrate inside the pipeline builder.
- Routes Plan review through the existing validation and retry-loop mechanisms, including revision after validation failure.
- Adds Plan Scenes as the initial bridge from a validated plan toward downstream scene-oriented execution.
- Separates planning schema families so the architecture can grow more cleanly, while the longform scene-planning family remains the mature exposed path for now.

Known follow-up:
- This is not a complete universal planning framework yet; broader schema families, approval gates, and full downstream media orchestration remain future work.
