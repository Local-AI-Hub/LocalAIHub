# v0.21.0 - Pipeline mapping, model-manager reliability, wizard robustness, and backend readiness

## Highlights

- Adds collectionMap / Map Collection support for text-collection to image-collection workflows, including Forge validation.
- Improves Forge and Automatic1111 readiness checks, API handling, and launch-path clarity for image pipeline use.
- Hardens Model Manager artifact selection, download planning, downloaded-state identity, and hardware-fit scoring.
- Expands Pipeline Wizard drafting and lowering across collection-aware, multimodal, file, video, image-transform, audio-generation, and audio-transform workflows.
- Improves credential resolution and redaction so secrets can come from environment variables without being exposed in logs or verifier output.

## Pipeline and wizard

- Drafts collection-aware graphs and lowers multimodal, file, and video inputs more consistently.
- Adds bounded wizard lifecycle handling and timeout behavior.
- Adds a Gemini/native structured-output harness path for more reliable wizard responses.
- Fixes wizard message text normalization.
- Expands wizard exposure for audio generation, audio transform, video generation, and image transform.
- Removes stale audio output ports and lets graph workflow contracts drive visible ports.
- Allows compatible ComfyUI graph workflows to act as collectionMap operation backends when configured.

## Model Manager

- Avoids presenting support/component files as runnable checkpoints.
- Improves Hugging Face, CivitAI, Ollama, Tabby, and GGUF result handling.
- Improves model search/result shaping and download-plan verification.
- Tracks downloaded state more accurately with sidecar metadata.
- Uses more conservative hardware-fit scoring for lower-end systems.

## Local tools and readiness

- Adds shared local image backend selection.
- Clarifies Forge and Automatic1111 behavior in readiness and pipeline paths.
- Keeps Fooocus honest: it remains launchable from the Library where available, but is not presented as a pipeline-runnable backend.

## Security/credentials

- Adds environment-variable credential support through a shared credential resolver.
- Improves redaction and log-safety paths across provider and process handling.
- Adds verifier coverage for credential safety without printing secret values.

## Verification and known limitations

Validated in this release pass:

- Model download plan verification.
- Provider credential security verification.
- Forge pipeline readiness verification.
- Local image backend selection verification.
- collectionMap pipeline verification.
- Pipeline wizard lifecycle verification.
- Pipeline media composition verification.
- Production UI build.

Known limitations:

- Fooocus is still not pipeline-runnable.
- ComfyUI remains graph-native; it is not a fake generic Automatic1111/Forge-style backend.
- collectionMap is not universal for all media operations.
- Per-item validation/retry inside collectionMap is not implemented.
- Split GGUF bundle installs remain blocked until multi-file model download support exists.
- Some heavy local video generation paths remain hardware-gated and may not be testable on GTX 1060-class hardware.
