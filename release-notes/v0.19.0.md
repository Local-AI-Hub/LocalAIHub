## Local AI Hub v0.19.0

- Bounded pipeline wizard release built on the existing pipeline and planning substrate.
- Adds a pipeline-tab wizard entry that turns a plain-English workflow request into an editable grounded draft graph inside the existing builder.
- Introduces Wizard Intent IR and compiler flow, plus obligation and constraint repair to better preserve requested modality, validation, retry, and control structure.
- Improves request-vs-runtime separation so generated drafts stay more honest about what still needs real runtime inputs and manual refinement.
- Improves local wizard and Ollama model refresh behavior, bounded local failure handling, and local recommendation/fallback messaging.
- Manual testing now shows structurally correct editable drafts for key cases including image-description-validation flows, planning-aware prompt-collection flows, and composition-oriented requests.

Known follow-up:
- This is not a complete autonomous workflow engineer; the wizard is still a bounded drafting layer over the existing pipeline system.
- Local models remain weaker on more complex requests, and some pipeline capability gaps outside the wizard still remain, including collection-validation support.
